# Quantitative Risk Analysis (QRA) Data Pipeline Practice

## Overview

This repository contains Python scripts demonstrating the core data engineering pipeline for Quantitative Risk Analysis:

1. **Data Ingestion**
2. **Data Cleaning**
3. **Data Validation**

## Datasets Used

- **Project Risk & Earned-Value Dataset** (Mendeley Data)
- **MSME-RiskX Credit Risk Dataset** (IEEE DataPort)

## Project Structure

- `data/`: Local directory for datasets (ignored by Git).
- `src/`: Python scripts for ingestion, cleaning, and validation.
- `requirements.txt`: Required Python dependencies.
